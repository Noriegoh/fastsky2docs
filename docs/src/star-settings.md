# Star Settings

The star field is rendered behind the sun and moon. You can modify the star field's appearance using the settings below.

| Property          | Function                                                                                                 |
| ----------------- | -------------------------------------------------------------------------------------------------------- |
| Scale             | The size of the star field.  This is a [static parameter](glossary#static-parameter)                     |
| Depth             | Depicts the illusion of distant and close stars. This is a [static parameter](glossary#static-parameter) |
| Size              | The size of the stars.                                                                                   |
| Brightness        | The brightness of the stars.                                                                             |
| Twinkle Speed     | The speed of the twinkle effect.                                                                         |
| Twinkle Intensity | The intensity of the twinkle effect.                                                                     |
