# Fog Settings

The atmospheric height fog (aerial perspective) creates the illusion of fog in the distance.
It is similar to Unity's fog system, but with height support and it integrates well with the atmosphere.

| Property   | Function                                                                                                                                                                   |
| ---------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Density    | Controls the density of the atmospheric fog (aerial perspective) effect on scene geometry. At '0' the effect is disabled.                                              |
| Max Height | The maximum height of the fog. Fog is faded out above this height.                                                                                                              |
| Height Falloff | The transition zone height over which fog fades from full to zero.                                                                                                       |
| Tint       | The tint of the atmospheric fog.                                                                                                                                           |
| Noise      | The noise texture used to warp the fog boundary.                                                                                                                         |
| Noise Amplitude | The amplitude of the fog noise.                                                                                                                                        |
| Noise Scale | The scale of the fog noise.                                                                                                                                                |
| Noise Drift Speed | The speed at which the fog noise drifts.                                                                                                                                 |
